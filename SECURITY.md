# Security & Abuse Policy

**uo.wzk.cz — Ultima Online Tools Archive** is a static preservation archive of
community-made Ultima Online tools, mostly 15–25 years old. Files are republished
as-is from sites that no longer exist. We take reports about harmful content seriously.

## What to report

- A download flagged as malware, a potentially unwanted program, or otherwise harmful
- Content that infringes your rights (e.g. you are the author and want it removed or updated)
- Phishing, spam or misleading content anywhere on the site
- A security problem with the website itself (hosting, headers, scripts, this repository)

## How to report

- **Privately (preferred for security issues):**
  [Report a vulnerability](https://github.com/MyKEms/uo.wzk.cz/security/advisories/new)
  via GitHub private vulnerability reporting.
- **Publicly (content issues, false positives, removal requests):**
  [open an issue](https://github.com/MyKEms/uo.wzk.cz/issues/new).

Please include the URL, what you observed (e.g. antivirus name and detection,
VirusTotal link or SHA-256) and any other evidence.

## What happens next

1. Every report is **reviewed manually** — we don't rely on automated verdicts alone.
2. While a report is investigated, a questionable file may be taken offline as a precaution.
3. We then take the appropriate action: remove or replace the file, correct the
   description, add a warning, or restore it if the report was a false positive.
4. We reply on the report with the outcome.

Files removed for security reasons are never re-published on the website.
We aim to respond within a few days; this is a volunteer-run archive with no SLA.

## Scope and limitations

- Archived tools are third-party software provided **without any warranty**.
  Run old executables only on systems you are comfortable with (ideally a VM),
  and scan downloads with an up-to-date antivirus.
- Heuristic detections on old, unsigned Delphi/VB tools and client patchers are
  common; we still review each one.
- Cloudflare hosts the site; abuse reports sent to Cloudflare reach us as well.
