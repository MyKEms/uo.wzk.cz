This is a volunteer-run preservation archive of old Ultima Online tools. Files are republished as-is from community sites that no longer exist, so we take reports about harmful or unwanted content seriously.

## Report a problem

- **Security issue or malicious file** — report privately via [GitHub private vulnerability reporting](https://github.com/MyKEms/uo.wzk.cz/security/advisories/new).
- **False positive, copyright or removal request, wrong information** — [open an issue on GitHub](https://github.com/MyKEms/uo.wzk.cz/issues/new).

Please include the page URL, what you saw (antivirus name and detection, VirusTotal link or SHA-256) and any other evidence.

## How we handle reports

1. **Every incident is reviewed manually** — automated verdicts alone are not enough to keep or remove a file.
2. A questionable file may be taken offline as a precaution while we investigate.
3. We take the appropriate action: remove or replace the file, correct the description, add a warning, or restore it if the report turns out to be a false positive.
4. We reply with the outcome.

Files removed for security reasons are not re-published on this site.

## Using archived tools safely

Archived tools are third-party software from 2000–2019, provided **without any warranty**. Many are unsigned Windows executables that some antivirus products flag heuristically. Scan every download, and run old tools only on systems you are comfortable with — ideally a virtual machine.

The source of this website, including the full [security policy](https://github.com/MyKEms/uo.wzk.cz/blob/main/SECURITY.md), is on [GitHub](https://github.com/MyKEms/uo.wzk.cz).
