Dialog Studio 1.4 (Final) is a visual dialog and gump designer for Sphere server. It provides a WYSIWYG editor for creating in-game dialog windows (gumps) with buttons, text fields, images, and checkboxes, then exports the SCP script code ready to paste into your Sphere server scripts. The tool includes a built-in item browser with UO core data files for previewing gump elements. Contains 196 files including templates and documentation.
