AGC (Automated Game Controller) 5.0 Beta 2.4 is an automation and game control tool for Ultima Online. It provides programmable macro sequences and automated game actions through a configuration-based interface (settingsV5.cfg). AGC was designed for repetitive in-game tasks on private servers.
