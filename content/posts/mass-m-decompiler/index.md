Mass M Decompiler (Publish 7) is a decompilation and analysis tool for Ultima Online server scripts and data. It includes a VB.NET UO Demo Class Library for programmatic access to UO data structures. Contains 232 files across multiple projects — useful for reverse engineering game mechanics or migrating scripts between server platforms.
