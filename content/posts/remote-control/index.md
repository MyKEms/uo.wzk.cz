Remote Control is a suite of remote administration tools for UO server management, with a focus on Sphere server. The primary component, RemoteSphere, is a Java-based application that allows connecting to and managing a Sphere server remotely, with syntax highlighting for commands. The archive is comprehensive at 75 MB, containing multiple remote admin tools and documentation.
