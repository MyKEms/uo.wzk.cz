POL (Penultima Online) is an alternative Ultima Online server emulator written in C++ with an eScript scripting language. Unlike RunUO's C# approach, POL uses its own lightweight scripting system designed specifically for UO server development. POL was popular in the European freeshard community and offered excellent performance for large player counts. This archive contains the full source code with build system (CMake), test suites, and documentation.
