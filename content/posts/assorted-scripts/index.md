A comprehensive collection of script archives for multiple UO server platforms. Includes the Complete RunUO Script Archive (48 MB, September 2013), Complete Orbsydia Script Archive (10 MB), Daat99 OWLTR (Old World Loot and T-Map Revamp) for RunUO 2.0, custom RunUO scripts, the SphereServer Community Script Pack (r367), and UOSteam custom macro scripts. An invaluable resource for shard developers looking for pre-built game systems and content.
