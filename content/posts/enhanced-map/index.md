Enhanced Map 0.2.1.12 is a real-time map overlay application for Ultima Online, often used as a companion to Razor Enhanced. It displays your character position on a detailed map with support for custom markers, location definitions (banks, shops, guilds, etc.), party tracking, and configurable map layers. The definitions directory includes categorized location data for various points of interest across Britannia.
