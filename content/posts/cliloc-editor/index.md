Cliloc Editor 2 is a tool for editing Ultima Online's cliloc (Client Localization) files. These files contain all the text strings displayed in the UO client — item names, system messages, skill descriptions, spell names, and more. Shard developers use this editor to customize text for localized or custom content servers. The editor allows searching, editing, adding, and removing text entries by their numeric cliloc ID. Essential for any shard that needs custom item names or translated content.
