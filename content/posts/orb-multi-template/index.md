OrB Multi Template Manager 1.0 is a tool for managing and editing multi (building/structure) templates in Ultima Online. It provides an organized interface for creating, importing, and modifying multi definitions used for houses, castles, and other in-game structures. Part of the OrB (Orbsydia) suite of UO development tools.
