A custom installer for Notepad++ 4.1.2 preconfigured with syntax highlighting for Sphere SCP (Server Control Program) script files. Provides color-coded editing for Sphere server scripts with proper recognition of SCP keywords, section headers ([ITEMDEF], [CHARDEF], [DIALOG], etc.), triggers (ON=), and properties. Makes editing large Sphere script packages significantly more productive than using a plain text editor.
