AutoIt Warlock Script is an automation script written in AutoIt for Ultima Online. AutoIt is a general-purpose Windows automation scripting language, and this script package provides UO-specific automation macros. Unlike EasyUO which hooks into the client, AutoIt scripts work at the OS level through simulated keyboard and mouse input.
