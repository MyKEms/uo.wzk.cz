Razor Enhanced is the most feature-rich fork of the classic Razor UO assistant. It extends the original with a built-in Python-based scripting engine, enhanced macro capabilities, an integrated script editor, and improved compatibility with modern UO clients. The archive includes Razor Enhanced 0.6.62, the EnhancedMap companion application (a real-time map overlay), the Enhanced updater, the Alexdan script library, and the full source code repository. At 178 MB this is a comprehensive package for any UO player.
