Client Auto Update 0.87 is a patching and auto-update system for UO freeshard clients. It allows shard operators to distribute client file updates to their players automatically. When players launch the updater, it connects to the shard's patch server, checks for new files, and downloads only the changed content. Simplifies the process of pushing custom art, map changes, or configuration updates to the player base.
